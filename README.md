## Структура проекта (Лабораторная работа №1)

В рамках первой лабораторной работы реализована объектно-ориентированная доменная модель предметной области "Автомойка".

### Основные сущности (`CarWash.Domain`):
* `Car` — Автомобиль клиента (госномер, марка).
* `Client` — Клиент автомойки (ФИО, телефон, список автомобилей).
* `Service` — Услуга (название, категория ТС, цена, длительность).
* `Order` — Заказ на обслуживание (выступает в роли контракта). Содержит информацию о клиенте, услуге, авто, номере бокса и времени начала. Имеет вычисляемое свойство времени окончания.
* `CarCategory` — Перечисление категорий ТС (Легковой, SUV, Грузовой, Минивэн).

### Юнит-тестирование и бизнес-логика (`CarWash.Tests`):
Реализована тестовая фикстура `CarWashFixture`, содержащая репрезентативный набор данных (Data Seed): 10 клиентов, 10 автомобилей, 10 услуг и 21 заказ.

С помощью `xUnit` и `LINQ` покрыты следующие бизнес-сценарии:
1. Вывод Топ-5 клиентов по количеству посещений.
2. Получение списка автомобилей, находящихся на мойке в заданный момент времени.
3. Вывод Топ-5 наиболее популярных услуг.
4. Расчет ближайшего свободного времени для выбранного бокса мойки.
5. Подсчет суммарной выручки в разрезе каждой услуги.
